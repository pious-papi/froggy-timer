# Ribbit Focus - ADHD Pomodoro Clock

An 8-bit, paper-esque minimalist Pomodoro timer tuned specifically to eliminate distraction and lower sensory friction for people with ADHD. Features a state-driven ASCII flipbook animation of a frog watching an emptying hourglass.

## How to Run Locally

Follow these precise steps to spin up the application on a fresh machine.

### Prerequisites
Ensure you have Node.js (v18.x or later) and npm installed on your system.

### 1. Extract and Navigate
Open your terminal inside the project directory:

```bash
cd adhd-frog-timer
```

### 2. Install Dependencies
Install the required Next.js, React, and Tailwind dependencies:

```bash
npm install
```

### 3. Launch Development Server
Boot up the engine locally:

```bash
npm run dev
```

### 4. Open in Browser
Open your browser and navigate to the address printed in your terminal:
http://localhost:3000
